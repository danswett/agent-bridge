Agent Bridge

A session is a node. Its delegates orbit it. Everything else follows the platform you’re on.

Ours: what things mean
Status glyphs, status colours, the icon set, the mark, and the session → agent → delegate hierarchy are identical everywhere.
Theirs: how it’s built
Window chrome, navigation pattern, controls, materials, type family, motion and gestures come from Windows, macOS, iOS or Android.
Order is yours
Rows never move on their own. Only a question floats, into Needs you, and its row stays put.
One voice per line
The main stream is the main agent only. Every delegate line is on its own row and names who wrote it.

Status glyphs

One shape per state, so they read without colour and in high contrast. Drawn on a 16 grid, scaled to 14 (dense lists), 16, 20 and 24.

Needs you
A question or approval is waiting. Filled: the only solid glyph.
Working
The arc turns, once per 1.2 s. Still under reduced motion.
Delegating
Main agent idle, delegates in orbit. Satellites drift slowly.
Idle
Nothing running. Neutral, never coloured.
Driven by an agent
Any state, plus the violet diamond; working turns violet.
Finished
Delegates only. Neutral: done isn’t news.
Failed or stopped
Delegate aborted, launch failed, host unreachable.
Ended
Session gone; kept in the Ended group.

Colour roles

Five roles, light and dark. Bridge teal is for controls and selection; status colours are never used on controls.

RoleDarkLight Bridge · primary actions, selection, mark Needs you · questions, approvals Active · working, delegating Agent · driven by an agent, only Danger · failed, end session

Surfaces and text come from the platform: Mica and layer fills on Windows, window and sidebar materials on macOS, system grouped backgrounds on iOS, Material tonal surfaces on Android (seeded from Bridge teal; dynamic colour off for status roles). High contrast maps every role to system colours.

Icons

Our own set, 20 grid, 1.5 stroke, round ends, one weight. Used in place of Segoe Fluent, SF Symbols and Material Symbols so the app reads the same on every device; sizes follow each platform (16 and 20 on desktop, 22–24 on phones).
